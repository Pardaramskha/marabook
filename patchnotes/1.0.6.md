## 1.0.6 - "Here it comes!" (25/10/2026)

### Fonctionnalités majeures
* Ajout de l'updater de version Beta : certaines versions expérimentales pourront être rendues disponibles avant leur sortie officielles pour êtres testées. Attention : n'utilisez JAMAIS de version beta avec votre projet principal, celles-ci étant susceptibles d'avoir des bugs et de provoquer des erreurs dans vos fichiers.
* Ajout de nouvelles animations dans les panneaux
* Refonte visuelle des préférences
* Ajout d'un recadreur d'image pour les Fiches
* Ajout de statistiques à l'échelle du Livre dans l'onglet Publication

### Fonctionnalités mineures
* Ajout de l'option de désactivation des animations dans les préférences
* Ajout d'un correcteur d'enchainement de pages/chapitre pour les livres (afin que tout démarre sur une impaire et se finisse sur une paire pour les besoins du manuscrit PDF).
* Ajout de nouveaux avertissements pré-publication dans l'onglet Publication.
* Ajout de l'option d'enchainement de chapitres dans Gabarit & Format des Livres (voir plus haut).
* Refonte visuelle des avertissements pré-publication.

### Correctifs
* Les lignes lâches sont désactivées par défaut.
* Correctif de placement de guillemets après une exclamation.
* Optimisation de l'affichage des images dans les Fiches
* Correctif de l'affichage des fenetres trop hautes sur les écrans trop petits (git gud)

### Note importante
L'optimisation des images ne concernera que les images importées après cette mise à jour - vos images précédemment importées resteront telles quelles.
